# FOSS Mapping Benchmark

A routing benchmark application for comparing routes generated by open-source mapping and routing engines with Google Maps.

The goal of this project is to understand how different routing engines calculate routes between the same starting point and destination, and to compare their distance, duration, and route geometry.

## Features

- Enter a starting address and destination address
- Convert addresses into coordinates using Nominatim
- Calculate routes using multiple routing providers
- Compare:
  - OSRM
  - Valhalla
  - Google Routes API
- Display all three routes on an interactive MapLibre map
- Compare route distance and duration
- Store benchmark cases and routing results in PostgreSQL
- Expose routing functionality through a Spring Boot REST API
